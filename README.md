# APKlyst

Les applications Android que je développe, publiées ici en installation directe.

Aucune ne passe par le Play Store : vous téléchargez le fichier `.apk` et vous l'ouvrez
depuis votre téléphone.

| Application | Version | Description |

| [Billy](Billy/) | 1.4 | Suivi des prélèvements mensuels et des dépenses par carte, à une ou plusieurs personnes. |

## Installer une application

1. Ouvrez le dossier de l'application et téléchargez son fichier `.apk`.
2. Ouvrez le fichier depuis votre téléphone. Android demandera l'autorisation d'installer
   des applications provenant de cette source : elle ne concerne que l'application qui ouvre
   le fichier — Drive, Fichiers, votre navigateur — et ne se donne qu'une fois.
3. Un avertissement de Play Protect s'affiche, l'application ne venant pas du Play Store.
   Poursuivez l'installation.

## Mettre à jour

Téléchargez la nouvelle version et ouvrez-la : elle s'installe par-dessus l'ancienne, sans
désinstallation et sans perdre vos réglages. Toutes les versions publiées ici sont signées
avec la même clé, ce qui rend cette mise à jour directe possible.
